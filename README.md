## My process

This project was built step-by-step as follows:

- First, the basic HTML structure was written, and the rest of the code started by placing a single `div` tag inside the body.
- Right away, I set the background color and used a Flexbox at the same time to center the rest of the content.
- After that, for each HTML section, its corresponding CSS style was implemented right after.
